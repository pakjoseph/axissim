# Synthetic burst-stress release trace

This is a deterministic, illustrative stress input created for AxisSim's
release-trace sensitivity tests. Frames 0–3 arrive 100 microseconds apart;
subsequent frames are spaced at 33,333 microseconds. It is **not** a measured
camera/sensor trace and must not be used to claim field-sensor robustness.

Units are microseconds. Generated 2026-11-04 from the documented values above.
